ONDA PRINTING — VERSI HTML
===========================

Isi folder:
- index.html       : halaman utama
- about.html       : halaman tentang
- services.html    : halaman layanan
- portfolio.html   : halaman portofolio
- contact.html     : halaman kontak
- assets/style.css : seluruh tampilan website
- assets/script.js : menu mobile, filter portofolio, dan form kontak

CARA MEMBUKA
Klik dua kali index.html. Website dapat berjalan langsung tanpa instalasi.

CARA MENGUNGGAH
Unggah seluruh isi folder ini ke public_html, htdocs, atau folder utama hosting.
Jangan mengubah susunan folder assets.

CATATAN
- Nama, alamat, telepon, statistik, dan karya masih merupakan contoh.
- Form kontak saat ini hanya menampilkan konfirmasi di browser. Agar pesan
  benar-benar terkirim, sambungkan form ke Formspree, Netlify Forms, atau backend.
- Gambar social preview sudah tersedia sebagai assets/og-onda.png.
